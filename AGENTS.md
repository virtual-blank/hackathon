# AGENTS.md

Инструкции для AI-агентов (Claude Code и др.). Проект — трекер привычек с
соцсетью: друзья, чат, общие привычки, достижения, уведомления в Telegram.

## Стек и структура

Python 3.12 · FastAPI · SQLAlchemy 2 (async, asyncpg) · PostgreSQL · Alembic ·
Pydantic 2 · Poetry.

```
backend/
  main.py            точка входа FastAPI, регистрация роутеров
  core/config.py     настройки (pydantic-settings)
  database/          Base, сессия, миксины, str_enum
  alembic/           миграции
  src/
    auth/            JWT, хеш пароля, зависимости (SessionDep, CurrentUserDep)
    exceptions/      исключения приложения
    {domain}/        users · habits · social · analytics · telegram
frontend/
docker-compose.yml
```

Корень импортов — `backend/` (`from src.users...`, `from core.config...`,
`from database.db...`), поэтому команды запускаются оттуда:

```bash
cd backend
poetry install
poetry run fastapi dev main.py
poetry run alembic upgrade head
```

Настройки читаются из `.env` в корне репозитория. `.env` не коммитим.

## Ключевые правила

### Источники знаний

**О чужой библиотеке спрашиваем актуальную документацию, а не память**
(context7 через MCP, если подключён). Любой вопрос про API или поведение
FastAPI, SQLAlchemy, Pydantic, Alembic — **до** написания кода, а не после
того, как оно упало: знания модели о версии библиотеки устаревают молча, и
придуманный аргумент выглядит правдоподобно. Версии брать из `poetry.lock`,
а не из `pyproject.toml`: там диапазоны.

### Архитектура

1. **Слои внутри домена:** `router.py` → `service.py` → `repository.py`.
   Обратные зависимости запрещены: репозиторий не знает про сервис, сервис —
   про роут и HTTP.
2. **Структура домена** в `backend/src/{domain}/`: `router.py` · `service.py` ·
   `repository.py` · `schemas.py` (Pydantic) · `models.py` (SQLAlchemy) ·
   `enums.py`. Новый файл — только когда содержимое не подходит ни одному из
   этих.
3. **Роут тонкий:** распарсить вход → вызвать сервис → вернуть схему.
   Бизнес-логика — в сервисе.
4. **Сервис и репозиторий — классы, получающие `AsyncSession` в конструкторе.**
   Сессия приходит в роут через `SessionDep` (`src/auth/deps.py`), роут создаёт
   сервис, сервис — репозиторий. Образец — `src/users/`.
5. **Текущий пользователь** — `CurrentUserDep` / `CurrentUserIdDep` из
   `src/auth/deps.py`. Свой разбор токена в роутах не пишем.
6. **Домены общаются через сервисы и репозитории друг друга**, а не лезут в
   чужие таблицы своими запросами.
7. **Третья копия — повод вынести общее.** Один и тот же кусок в трёх местах
   уезжает в общий модуль; различия задаются параметрами, а не клоном файла.

### Python

1. **Функции по умолчанию.** Класс — когда есть состояние между вызовами
   (сервис и репозиторий с сессией), данные (`BaseModel`) или ресурс, который
   надо закрывать. Класс, в котором `__init__` только раскладывает аргументы, а
   метод один, — это функция.
2. **Pydantic — для всего на границе:** тело запроса, ответ, ответ внешнего
   API. Сырой `dict` между слоями и наружу не пробрасывается.
3. **ORM-модель → схема** — `Schema.model_validate(orm_obj)` при
   `ConfigDict(from_attributes=True)`. Поля руками не перекладываем.
4. **Модель — минимум полей.** Не заводи поле, которое выводится из других:
   `@computed_field` / `@property`. Каждое поле — контракт, который придётся
   синхронизировать.
5. **Type annotations обязательны** у параметров и возвращаемого значения.
   Синтаксис `list[X]`, `X | None`. `TYPE_CHECKING` — для разрыва циклических
   импортов между моделями.
6. **Async-first:** `httpx`, не `requests`. **`async` — только когда внутри
   есть `await`**: лишний `async` делает асинхронной всю цепочку вызывающих.
7. **Двойные кавычки**, как в существующем коде.
8. **Без односимвольных переменных**, даже в циклах и comprehension'ах:
   `habit`, не `h`.
9. **Поле — существительное, а не действие:** `pending_items`, не
   `items_to_send`. Причастие состояния (`processed`) и булев предикат
   (`is_read`) допустимы.
10. **Не возвращай безымянные составные структуры.** `tuple[User, list[int]]`
    на месте вызова превращается в распаковку, о смысле которой надо
    догадываться. Больше одного значения — схема или dataclass.
11. **Модуль называется по содержимому.** `helpers.py` / `misc.py` /
    `common.py` / `utils.py` — заявка на мусорку. Не находится имя — в файле
    лежат две разные вещи.
12. **Константа — по числу читателей.** Одно место — константа не нужна.
    Несколько мест в одном файле — на уровне этого файла. Магический литерал,
    по которому принимается решение (`if streak >= 7`), получает имя всегда.
13. **Настройки** — класс `BaseSettings` с `env_prefix` в `core/config.py` и
    фабрика `get_<name>_settings()` под `@lru_cache`. Секреты — только из env.
14. **Логирование — `logging`, не `print`.** В `except` — `logger.exception(...)`.
    Не логировать успешный CRUD и «функция вызвалась».
15. **Комментарии — только ПОЧЕМУ.** Не пересказывай код и не оставляй
    комментарии-ответы на промпт («выбрал X вместо Y, потому что…»).
16. **Suppress линтера — только с обоснованием** рядом (`# noqa`,
    `# type: ignore`): почему правило нельзя починить.

### База данных

1. **БД — только через репозиторий.** Никаких `select` / `insert` / `update` /
   `delete` в сервисах и роутах.
2. **Никаких сырых SQL** (`text('SELECT ...')`) — SQLAlchemy expression
   language. `text()` — крайний случай.
3. **Одна бизнес-операция — одна транзакция.** `commit()` явный. Проверку и
   запись, которые должны быть атомарны, не разносим по разным коммитам.
4. **Guard-rails:** `if not ids: return {}` — ранний выход вместо пустого
   запроса.
5. **ORM-модели:** наследуем `Uuid7PkMixin, TimeStampMixin, Base` —
   первичный ключ UUIDv7 и `created_at` / `updated_at` приходят сами.
   `__tablename__` — snake_case, множественное число. `Mapped[...]` /
   `mapped_column(...)`; nullable выражается типом (`Mapped[int | None]`).
6. **Enum в БД — через `str_enum(...)`** из `database/enum.py` (VARCHAR, а не
   нативный тип Postgres): новое значение добавляется без `ALTER TYPE`.
7. **Имена констрейнтов и индексов руками не задаём** — их генерирует
   `NAMING_CONVENTION` в `database/db.py`.
8. **Типы колонок:** `String(n)` с длиной, `DateTime(timezone=True)` всегда.
9. **Идентификатор внешней системы не может быть нашим первичным ключом.**
   `telegram_chat_id` — отдельная колонка с `unique`; ссылки между нашими
   таблицами идут по нашему `id`.
10. **Индексы — только под реальные запросы.** Каждый индекс замедляет запись.
11. **Не храни вычисляемые поля** — `@property`, а не колонка: иначе
    рассинхрон.
12. **NULL в `UniqueConstraint`** = дубли просочатся (в Postgres
    `NULL != NULL`).
13. **Миграции:** изменить модель → `alembic revision --autogenerate -m "..."`
    → **прочитать файл** (изменение попало, лишнего нет, нет потери данных) →
    `alembic history` (один head) → `alembic upgrade head`. Новый модуль
    `models.py` импортируем в `alembic/env.py` и `main.py` — иначе
    автогенерация его не увидит.

### API / роуты

1. **REST-стиль:** путь — ресурс (существительное, множественное число),
   действие задаёт HTTP-метод. Без глаголов в пути: не `/habits/create`.
2. **CRUD-маппинг:** `GET /habits` · `GET /habits/{id}` · `POST /habits` ·
   `PUT /habits/{id}` · `PATCH /habits/{id}` · `DELETE /habits/{id}`.
3. **kebab-case** для составных ресурсов: `/habit-logs`.
4. **Вложенность под-ресурсом:** `GET /habits/{id}/logs`. Фильтры, пагинация и
   сортировка — в query.
5. **Не-CRUD действие — как ресурс**, не RPC-глагол: отметка выполнения →
   `POST /habits/{id}/logs`. Исключение — аутентификация (`/users/login`).
6. **Вход и выход — Pydantic-схемы** из `schemas.py`; `response_model` указан.
   `dict` из роута не возвращаем.
7. **`router = APIRouter(prefix="/<resource>", tags=[...])`**, регистрация —
   `include_router` в `main.py` с `ROUTERS_PREFIX`.

### Ошибки

1. **Сервис бросает исключение**, а не возвращает `None` / код /
   `{"error": ...}`.
2. **Не бросай `HTTPException` из сервиса** — HTTP не его слой. В статус
   исключение переводит роут.
3. **Свои типы ошибок** — классы в `src/exceptions/`.
4. **Текст ошибки показывается пользователю** — без внутренних деталей и
   стека. На неожиданную ошибку (500) — нейтральное сообщение, не `str(exc)`.
5. **Ловим `Exception`, а не `BaseException`** и не голый `except:` — иначе
   вместе с ошибкой глотаем отмену и остановку процесса.
6. **Побочные эффекты** (уведомление в Telegram, запись аналитики) не должны
   ронять основную операцию: `try` с `logger.exception`.

### Тестирование

1. **Дефолт — интеграционный тест через точку входа** (API-роут): он проверяет
   то, как код зовут на самом деле, и переживает переписывание внутренностей.
   Unit — для чистых расчётов (стрики, достижения), которые снаружи не видны.
2. **Проверяем состояние, а не поведение:** возвращённое значение и строки в
   БД, а не «сколько раз и с какими аргументами позвали».
3. **Настоящий Postgres, не sqlite** — иначе расходятся констрейнты и
   семантика `NULL`.
4. **Роуты тестируем через `httpx.AsyncClient` + `ASGITransport`**, не
   `TestClient`: он крутит приложение в другом event loop.
5. **Тест должен быть тупым:** подготовка → действие → проверки, весь сценарий
   виден на месте. Дублирование лучше абстракции.
6. **Приватные методы не тестируем** — тестируем публичную точку входа.
7. **Красный тест в репозитории не оставляем.**
